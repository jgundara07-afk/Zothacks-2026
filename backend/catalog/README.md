# Collected opportunity catalog

`opportunities.json.gz` is a portable, compressed UTF-8 JSON file generated by:

```powershell
.\.venv\Scripts\python.exe -m opportunity_data.refine --export
.\.venv\Scripts\python.exe -m opportunity_data.export_app
```

It contains `{ "schema_version": 1, "opportunities": [...] }`. `manifest.json` records the count, checksum, source counts, exact personalization choices and categorization coverage. `sample.json` is a readable preview with two cards per source, not the full database. These files are project artifacts; they contain public-source opportunity records and editorial estimates, not API keys, private resume content or raw HTTP snapshots.

The default Flask app reads this file through `catalog_reader.py` and `program_catalog.py`. The core `/opportunities` route filters and paginates collected cards, and existing save/quest/completion routes accept collected IDs. Preparation quests are generated deterministically, while profile and activity state persists in the separate app store. `ONETHING_DATA_MODE=sample` keeps the explicit fictional fixture available. The lower-level `/catalog/options` and `/catalog/opportunities` routes remain read-only. Restart Flask after a manual export; no automatic collection occurs.

Fields retain the app's card naming (`id`, `title`, `description`, `organization`, `tags`, `goals`, `skills`, `kind`, `minutes`, `difficulty`, `mode`, `color`, `sample`) and add source links, `source_facts`, `status`, `collected_at`, coordinates, and `personalization`. `minutes` is the suggested preparation step; `personalization.duration` describes the larger opportunity. Full source descriptions and raw receipts remain in the local collector database; card descriptions are limited to 1,600 characters with `description_truncated` marking any truncation.

Read directly in Python:

```python
from backend.catalog_reader import load_catalog

catalog = load_catalog()
page = catalog.query(
    interests=["Web & App Development", "AI & Machine Learning"],
    goals=["Build a strong project portfolio"],
    scope="micro_step",
    challenge_levels=["Lazy"],
    time_buckets=["Under 5 min"],
    limit=20,
)
```

See [the filter API contract](../../docs/CATALOG_API.md) for exact semantics, including estimates, time boundaries, campus affiliation, unknown locations, and distance filtering. Generated files change only when explicitly rebuilt; no source refresh is scheduled.
